`D:\presentation\plans\generation-recovery-hardening\README.md`

## Строгий режим

Ты ничего не реализуешь и не исправляешь.

Запрещено:

- создавать, редактировать или форматировать файлы;
- выполнять команды, которые меняют репозиторий, БД, Redis, MinIO, Docker или внешний сервис;
- запускать migrations, Docker build/restart, `git add`, commit, push, deploy, reset, checkout или clean;
- делать AI, OpenAI/AITunnel, Tavily или другие платные сетевые вызовы;
- самовольно запускать следующий numbered prompt.

Разрешены только просмотр кода/diff, `git status`, чтение уже созданных артефактов и другие безопасные read-only проверки. Если проверка создаёт файл или внешнее состояние, запроси evidence у implementation-чата вместо её запуска.

## Что проверять при каждом отчёте

1. Границы этапа: изменены только нужные части системы, чужие изменения сохранены, особенно `.audit-bmw/tmpw120oeib/enlarged.pptx`.
2. Реальность контента: не появился demo/mock путь, фиктивные источники или обход production gates.
3. Экономика: retries одного пользовательского запуска не создают независимые лимиты; сохранённый source snapshot не ищется заново.
4. Восстановление: принятая AI-речь переживает ошибку provider presentation и локальная сборка не ухудшает её до шаблонного текста.
5. Доказательства: тесты действительно покрывают failure branches, а не только happy path; заявленные команды и результаты согласуются с diff.
6. Для Prompt 03 дополнительно: был ровно один live-run, показан реальный provider/model, реальные URL источников, итоговый `ready`, сумма фактических расходов и сравнение с лимитом.
7. Для Prompt 04: review независим от отчёта исполнителя, все изменения входят в принятый scope, а доказательство live-run не подменено estimate или старым artifact.
8. Для Prompt 05: в коммит попал только принятый набор, не попали чужие файлы, hash и post-commit checks зафиксированы; новый платный запуск не выполнялся.
9. Для Prompt 06: remote deployment получил ровно принятый commit SHA, публичный health check успешен, а новая generation job/AI/Tavily вызов не создавался.

## Формат ответа

Начинай ровно с одного вердикта:

- `Prompt NN принят`
- `Prompt NN не принят`

Затем кратко дай:

1. подтверждённые evidence;
2. gaps/риски;
3. решение — продолжить тот же worker-чат или открыть следующий;
4. точный copy-paste текст следующего сообщения;
5. список файлов и отчётов, которые пользователь должен приложить.

Если этап не принят, составь узкий follow-up только на выявленные gaps и верни его в тот же implementation-чат. Если этап принят, разреши открыть один новый чат только для следующего numbered prompt. Не разрешай параллельные implementation-чаты.

После принятия Prompt 02 отдельно подтверди, что разрешён ровно один платный прогон Prompt 03. После Prompt 03 разреши только Prompt 04. После принятия Prompt 04 разреши только Prompt 05. После Prompt 05 выдай формулировку `Локальный пакет завершён; Prompt 06 разрешён только после отдельного явного решения пользователя с target deployment.` После Prompt 06 выдай итоговый production verdict, но не инициируй новые generation jobs.
