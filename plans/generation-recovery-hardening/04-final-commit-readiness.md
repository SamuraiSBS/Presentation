# 04 — независимый commit-readiness review

## Роль

Это отдельный новый **read-only** чат Codex после принятого Prompt 03. Его задача — проверить не рассказ исполнителей, а весь текущий diff и сохранённые evidence перед коммитом.

Прочитай `AGENTS.md`, README пакета, prompts 01–03, решения координатора, все отчёты и текущий `git diff`. Не создавай и не меняй файлы.

## Запрещено

Не выполнять AI/Tavily вызовы, Docker build/restart, миграции, `git add`, commit, push, deploy, reset, checkout или clean. Не запускать команды, создающие artifacts. Это review, а не новая реализация.

## Обязательная проверка

1. Сопоставь каждый изменённый файл с Prompt 01 или Prompt 02; выдели отдельно уже существовавшие/чужие изменения.
2. Проверь, что общий лимит не умножается при повторе presentation job, а source snapshot reuse-ится без нового Tavily.
3. Проверь, что provider failure с принятой реальной речью ведёт к contract-aware local recovery, а не к demo/generic подмене.
4. Проверь реальное evidence единственного Prompt 03: один project/run, `ready`, provider/model, реальные URL источников, связность текста/notes/sources и ledger фактических RUB <= cap.
5. Проверь тестовые результаты, известные непроходящие тесты и отсутствие неподтверждённых утверждений.
6. Убедись, что `.audit-bmw/tmpw120oeib/enlarged.pptx` не будет включён в коммит.

## Формат ответа

Начни строго с одного из вариантов:

- `Commit readiness принят`
- `Commit readiness не принят`

Затем перечисли доказательства, gaps и точный scope файлов, которые разрешено закоммитить. Если принят, подготовь для координатора точный текст, разрешающий только Prompt 05. Если не принят, подготовь узкий follow-up в исходный implementation-чат; не исправляй ничего сам.
