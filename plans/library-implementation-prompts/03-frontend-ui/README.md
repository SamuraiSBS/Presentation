# Класс 03: Frontend UI

В этом классе собраны библиотеки для веб-интерфейса вокруг генерации, редактора и экспорта.

Используй этот класс, когда backend-генерация уже работает приемлемо, но пользователю нужен более спокойный, понятный и polished интерфейс.

## Библиотеки

- `TanStack Query`
  - Централизует загрузку проектов, mutations и polling статусов generation/export jobs.
  - Особенно полезен, потому что качественная генерация может идти дольше и ей нужен стабильный progress UI.
  - Лучшее первое frontend-инфраструктурное внедрение.

- `shadcn/ui`
  - Даёт UI-компоненты, код которых находится внутри проекта и легко кастомизируется.
  - Нужен для dialog, tabs, progress, inputs и аккуратных app controls.
  - Использовать выборочно, без полной переделки интерфейса.

- Radix UI
  - Даёт доступные headless primitives.
  - Нужен для надёжного поведения dialog, dropdown, tooltip, popover, tabs, switch под кастомным стилем StudyDeck.
  - Если `shadcn/ui` уже закрывает нужный primitive, не нужно дублировать его напрямую.

- `lucide-react`
  - Стандартизирует иконки в редакторе, экспорте, источниках и генерации.
  - Нужен для компактных tool buttons и быстро считываемых action/status элементов.
  - Уже есть в web workspace.
