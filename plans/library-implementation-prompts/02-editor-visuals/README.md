# Класс 02: Редактор и визуалы

В этом классе собраны библиотеки для минимального редактирования текста и более выразительных визуалов на слайдах.

Используй этот класс, когда содержание презентации уже достаточно хорошее, а следующий шаг - сделать слайды удобнее редактировать и визуально сильнее без полноценного Canva-подобного редактора.

## Библиотеки

- `Tiptap`
  - Добавляет удобное rich-text редактирование текста слайдов и речи докладчика.
  - Подходит текущему направлению продукта: сначала правим текст, а не двигаем вручную все элементы дизайна.
  - Не стоит хранить сложный editor JSON, пока shared-контракт презентации под это не готов.

- Mermaid
  - Добавляет автоматически сгенерированные академические диаграммы: процессы, классификации, timeline, причинно-следственные цепочки.
  - Полезен для защит и выступлений, где схема лучше очередного текстового блока.
  - Нужны безопасные fallback-варианты для web и export.

- `sharp`
  - Обрабатывает скачанные изображения перед сохранением в MinIO и экспортом.
  - Нужен для resize, compression, нормализации формата и сохранения размеров изображения.
  - Уже есть в проекте; задача - превратить его в явный image pipeline.

- React Flow
  - Более поздний вариант для сложных графовых визуалов.
  - Нужен только если Mermaid перестанет хватать или понадобится интерактивное редактирование диаграмм.
  - Не стоит внедрять до реальной продуктовой необходимости.
