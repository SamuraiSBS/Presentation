# Класс 01: AI-генерация

В этом классе собраны библиотеки и инфраструктура, которые напрямую влияют на качество сгенерированных презентаций.

Используй этот класс первым, если цель - сделать так, чтобы StudyDeck лучше создавал русскоязычные презентации для защиты по короткой теме.

## Библиотеки

- `Vercel AI SDK`
  - Даёт более чистый provider-neutral слой для структурированной AI-генерации, особенно для OpenAI.
  - Нужен для этапов: исследование темы, речь, план слайдов, финальная презентация, repair/polish.
  - При внедрении нельзя ломать существующую поддержку Yandex.

- `zod`
  - Держит AI-ответы в строгих shared-контрактах.
  - Нужен для проверки слайдов, речи, визуальных стратегий, quality critique и canvas-данных для экспорта.
  - Уже есть в проекте; задача - усилить и расширить использование.

- Tavily
  - Даёт фактический контекст для генерации по короткой теме без файлов.
  - Нужен для web-источников, grounding, поиска фактов и выборочного image search.
  - Должен оставаться опциональным, чтобы генерация могла продолжаться при сбоях поиска.

- `BullMQ`
  - Запускает долгие задачи генерации в фоне.
  - Нужен для staged progress, retry, логов задач и устойчивости worker.
  - Уже есть в проекте; задача - улучшить orchestration.
