AI-сервис для создания учебных презентаций по запросу и загруженным файлам

Позиционирование
Это учебный помощник для школьников и студентов. Пользователь вводит тему, прикрепляет учебник, статью, конспект, методичку или ссылку, а AI собирает понятную презентацию с планом, тезисами, источниками и текстом для выступления.

Главная идея
Не "сделай домашку за меня", а "помоги разобраться, структурировать материал и подготовиться к выступлению". Поэтому продукт должен показывать источники, объяснять сложные места простыми словами и помогать собрать понятный рассказ.

Для кого
- школьники: доклады, сообщения, проекты, защита исследовательской работы;
- студенты: семинары, презентации по статье, курсовые выступления, защита проекта;
- преподаватели: быстрые учебные слайды, план урока, раздаточные материалы;
- родители и репетиторы: помощь с подготовкой выступления без полной подмены работы ученика.

MVP
1. Пользователь вводит запрос и загружает PDF/DOCX/TXT/PPTX или конспект.
2. AI разбирает материалы, выделяет главное и предлагает план презентации.
3. Пользователь выбирает тип: школьный доклад, студенческий семинар, защита проекта, презентация по статье, урок.
4. AI создает слайды в понятной структуре данных, а не просто как кусок HTML.
5. Каждый важный тезис связан с источником, чтобы ученик мог объяснить, откуда взята мысль.
6. Есть редактор: список слайдов, рабочая область, AI-панель правок, заметки для выступления.
7. Экспорт: сначала PDF/PNG, затем редактируемый PPTX.

Чем отличается от Gamma для учебной аудитории
- учебные сценарии вместо универсального генератора: доклад, семинар, проект, защита, урок;
- режим "объясни проще": AI адаптирует материал под класс, курс и уровень подготовки;
- источники и список литературы: важно для школы, вуза и проверки преподавателем;
- learning mode: план, тезисы, пояснения и рассказ для выступления вместо слепого копирования;
- заметки спикера, тайминг и репетиция выступления;
- готовый экспорт в PDF/PPTX для сдачи или выступления.

Архитектура MVP
- Фронтенд: редактор на Next.js.
- Бэкенд: FastAPI или NestJS.
- База данных: PostgreSQL.
- Очереди задач: Redis + Celery или BullMQ.
- Хранилище файлов: S3-совместимое хранилище.
- AI-процесс: загрузка файлов -> извлечение текста -> поиск нужных фрагментов -> план -> слайды -> заметки спикера -> проверка источников -> экспорт.

Технический принцип
Презентация хранится как структурированный документ:
slides.content_json = blocks + layout + source references + speaker notes + assets.

Так презентацию проще редактировать, проверять, пересобирать по отдельным слайдам и экспортировать в PDF или PPTX.

Первые платные сценарии
- freemium для учеников и студентов с лимитом презентаций;
- подписка для активных студентов;
- школьные и вузовские лицензии;
- отдельный режим для преподавателей.
